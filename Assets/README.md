# Assets Directory

This directory contains all the visual and audio assets required for the Farmer's Math Feast game.

## Required Image Assets (.jpg)

### Tutorial and Title Screens
- `Opening & Tutorial.jpg` - Tutorial screen showing game instructions
- `Title Page.jpg` - Main title page of the game

### Background Themes
- `BG Theme 1.jpg` - Background theme option 1
- `BG Theme 2.jpg` - Background theme option 2
- `BG Theme 3.jpg` - Background theme option 3
- `Green bg.jpg` - Green background
- `autumn bg.jpg` - Autumn background
- `summer bg.jpg` - Summer background

### Game Screens
- `Game guide.jpg` - Game guide screen

### Mini-Game 1: Constellation
- `MiniGameOption1.jpg` - Mini-game 1 introduction screen
- `Mini-game 1 Constellation.jpg` - Constellation mini-game screen
- `Orion.jpg` - Orion constellation
- `Leo.jpg` - Leo constellation
- `Big Dipper.jpg` - Big Dipper constellation
- `Guess It.jpg` - Guessing game introduction
- `Guess Leo.jpg` - Leo constellation guessing screen
- `Guess Orion.jpg` - Orion constellation guessing screen
- `Guess Dipper.jpg` - Big Dipper constellation guessing screen

### Building the Scarecrow Mini-Game

### Ending Screens
- `Ending Page Feast.jpg` - Final ending page

## Required Audio Assets

### Music
- `feast-bgm.mp3` - Background music for the game

### Sound Effects
- `answer correct.mp3` - Sound effect for correct answers
- `level pass.wav` - Sound effect for passing a level
- `level fail.mp3` - Sound effect for failing a level

## Usage

All assets are referenced in the main `index.html` file and should be placed directly in this Assets directory. The game expects these exact filenames and will not function properly without them.
