# Assets Directory

This directory should contain the game assets required for the Farmer's Math Feast application to function properly.

## Required Image Files

The following image files are referenced by `index.html` and need to be placed in this directory:

### Main Screens
- `Title Page.jpg` - Title screen shown when the game starts
- `Opening & Tutorial.jpg` - Tutorial screen
- `Game guide.jpg` - Game guide screen
- `Ending Page Feast.jpg` - Final ending screen

### Background Themes
- `BG Theme 1.jpg` - Background for Level 1 (tutorial)
- `BG Theme 2.jpg` - Background for Level 2 transition
- `BG Theme 3.jpg` - Background for Level 3 transition
- `summer bg.jpg` - Summer background for Level 1 (Gathering Apples)
- `Green bg.jpg` - Green background for Level 2 (Collecting Eggs)
- `autumn bg.jpg` - Autumn background for Level 3 (Harvesting Carrots)

### Mini-Game Constellation Images
- `MiniGameOption1.jpg` - Mini-game option screen
- `Mini-game 1 Constellation.jpg` - Constellation introduction
- `Orion.jpg` - Orion constellation
- `Leo.jpg` - Leo constellation
- `Big Dipper.jpg` - Big Dipper constellation
- `Guess It.jpg` - Guessing game prompt
- `Guess Leo.jpg` - Leo guessing screen
- `Guess Orion.jpg` - Orion guessing screen
- `Guess Dipper.jpg` - Big Dipper guessing screen
- `ConstellationsFin.jpg` - Constellation game completion screen

### Encouragement/Scarecrow Activity Images
- `Birds and Bunnies.jpg` - Encouragement screen
- `Building the Scarecrow Intro page.jpg` - Scarecrow activity introduction
- `Building the Scarecrow Start.jpg` - Scarecrow activity start
- `Building the Scarecrow Q1.jpg` - Scarecrow question 1
- `Building the Scarecrow Q2.jpg` - Scarecrow question 2
- `Building the Scarecrow Q3.jpg` - Scarecrow question 3
- `Building the Scarecrow Q4.jpg` - Scarecrow question 4
- `Building the Scarecrow Q5.jpg` - Scarecrow question 5 (also used as final scarecrow image)
- `Scarecrow Complete.jpg` - Completed scarecrow

## Required Audio Files

The following audio files are needed for sound effects and background music:

- `level fail.mp3` - Sound played when a level is failed
- `level pass.wav` - Sound played when a level is passed
- `answer correct.mp3` - Sound played for correct answers
- `feast-bgm.mp3` - Background music for the feast ending

## File Format Notes

- Image files should be in JPG/JPEG format
- Audio files should be in MP3 or WAV format as specified
- Ensure file names match exactly (case-sensitive on some systems)

## Adding Assets

To make the game functional:
1. Place all required image and audio files in this directory
2. Ensure file names match exactly as listed above
3. Test the game by opening `index.html` in a web browser
